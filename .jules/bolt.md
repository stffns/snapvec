## 2024-05-18 - Fast row-wise Euclidean norm in pure NumPy
**Learning:** In performance-critical paths, computing the batch norm of a 2D array via `np.linalg.norm(arr, axis=1)` is relatively slow. Using `np.sqrt(np.einsum('ij,ij->i', arr, arr))` is significantly faster (~4x speedup on a laptop CPU for typical batch sizes). If `keepdims=True` behavior is needed, appending `[:, np.newaxis]` matches the original shape seamlessly.
**Action:** Always prefer `np.sqrt(np.einsum('ij,ij->i', arr, arr))` over `np.linalg.norm(arr, axis=1)` when computing row-wise vector norms in NumPy to eliminate dispatch overhead and improve execution speed.
## 2024-05-18 - Fast Dictionary Initialization and Updates
**Learning:** In Python, replacing manual dictionary update loops (e.g., `for i, v in enumerate(items): d[v] = start + i`) with `d.update(zip(items, range(start, start + len(items))))`, and dictionary comprehensions (e.g., `{v: i for i, v in enumerate(items)}`) with `dict(zip(items, range(len(items))))` provides a measurable performance boost. The `zip` and `range` methods are executed entirely in C within the Python interpreter, avoiding the overhead of evaluating bytecode for each loop iteration. My benchmarks showed a ~1.45x speedup for updates and a ~1.07x speedup for comprehensions on large lists.
**Action:** Always prefer `d.update(zip(keys, values))` and `dict(zip(keys, values))` over manual `for` loops with `enumerate` or dictionary comprehensions when constructing or updating dictionaries with sequences of elements in performance-critical Python paths.
